Babagan

SMK Bhakti Praja Batang ingkang rumiyin asmanipun STM, dipunadegaken tanggal 1 Juli 1979 dening Bupati Batang, Bapak Drs. Sukirjo. Sekolah punika wiwit resmi beroperasi ing taun 1981 kanthi jurusan Bangunan Gedung, lajeng malih nama dados STM Bhakti Praja Batang ing taun 1988. Wiwit taun pelajaran 2000/2001, sekolah punika malih dados SMK Bhakti Praja Batang kanthi Program Keahlian Teknik Mesin, Teknik Mekanik Industri, Teknik Mekanik Otomotif, lan salajengipun mbikak Program Teknik Sepeda Motor. SMK Bhakti Praja Batang sampun pikantuk status akreditasi “DIAKUI” lan ing taun 2018 pikantuk Akreditasi B kanthi nilai 85, ingkang dipunperpanjang malih ing taun 2021 dumugi tanggal 31 Desember 2026. Alhamdulillah, Program Keahlian Pengembangan Perangkat Lunak lan Gim (PPLG) ugi sampun lumampah kanthi sae lan pikantuk antusias masyarakat ingkang cekap ageng.

Program Pasinaon

Program ingkang wonten ing SMK Bhakti Praja Batang inggih menika

Teknik Mekanik Industri


Teknik Mesin Industri (TMI) ing SMK inggih menika jurusan ingkang maringi kawruh lan katerampilan teknis dhateng para siswa kangge ngrumat, ndandosi, lan ngoperasikaken mesin-mesin produksi ing industri manufaktur. Materi ingkang dipunsinaoni antawisipun bubut, frais, CNC, las (OAW/SMAW), sistem hidrolik-pneumatik, kelistrikan mesin, gambar teknik (CAD), saha K3. Kanthi punika, para lulusan dipunajab saged dados teknisi ingkang trampil lan profesional ing bidang industri manufaktur, otomotif, lan permesinan.

Teknik Kendaraan Ringan


Teknik Kendaraan Ringan (TKR) ing SMK inggih menika program keahlian otomotif ingkang nyiapaken para siswa dados ahli ing babagan pangopènan lan ndandosi kendaraan mobil lan motor. Materi ingkang dipunsinaoni antawisipun mesin, kelistrikan, transmisi, suspensi, saha sistem rem, kanthi langkung ngutamakaken praktik langsung wonten ing bengkel. Kajawi punika, para siswa ugi sinau teknologi injeksi lan komputerisasi kendaraan. Kanthi kawruh lan katerampilan punika, para lulusan dipunajab saged dados mekanik profesional, teknisi dealer, utawi mbikak bengkel piyambak, saha asring dipunjangkepi sertifikasi BNSP.

Teknik Sepeda Motor


Teknik Sepeda Motor (TSM) ing SMK inggih menika jurusan otomotif ingkang mulangaken babagan pangopènan, ndandosi, saha modifikasi sepeda motor kanthi langkung mendalam. Materi ingkang dipunsinaoni antawisipun mesin (karburator lan injeksi), kelistrikan, sasis, suspensi, dumugi sistem transmisi, kanthi tujuan nyetak mekanik profesional, teknisi ingkang trampil, utawi wirausahawan bengkel. Proses pasinaon kalampahan lumantar teori saha praktik langsung wonten ing bengkel kanthi standar industri. Jurusan punika sanget cocog kangge para siswa ingkang remen babagan mesin lan gadhah pepenginan nyambut damel ing bidang otomotif roda kalih.

Pengembangan Perangkat Lunak Lan Gim


Rekayasa Perangkat Lunak (RPL) ing SMK inggih menika jurusan kejuruan ingkang fokus wonten ing pangembangan perangkat lunak kados aplikasi, website, lan gim. Para siswa dipunwulang babagan pemrograman kados Java, Python, C++, JavaScript, desain UI/UX, basis data, saha jaringan komputer. Kanthi pasinaon punika, para siswa dipunajab saged dados tenaga ahli ing bidang teknologi informasi, kados developer, web designer, utawi IT support, kanthi prospek kerja ingkang wiyar ing industri teknologi.
